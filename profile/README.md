## 不止于提示词

模型提供基础能力。好的工程让这些能力成为可观察、可引导、可信赖的系统。我们关注人工智能系统周边的关键层：智能体运行时、Harness 工程、工具、知识和评测。

| 方向 | 我们关注的内容 |
| --- | --- |
| **智能体系统** | 状态管理、规划、记忆、工具调用、任务委派和受控执行。 |
| **Harness 工程** | 围绕智能体构建的运行时、接口、安全机制和反馈回路。 |
| **模型与工具编排** | 为模型、MCP 服务、外部工具和工作进程定义清晰的协作契约。 |
| **知识与检索** | 搜索、索引、知识依据，以及智能体工作流所需的上下文。 |
| **评测与可观测性** | 运行轨迹、可重复验证、故障分析和可衡量的改进。 |

## 从模型到可靠系统

<pre>
模型 → 上下文 → 智能体 Harness → 工具与执行 → 评测与运行轨迹
  ↑                                                        │
  └────────────────── 反馈与持续改进 ─────────────────────┘
</pre>

## 工程原则

<pre>
让状态清晰可见       →      让行为可以检查
为故障做好准备       →      让恢复成为正常流程
采用明确的契约       →      让系统组合更可靠
评估真实的行为       →      根据证据持续改进
</pre>

我们关注演示之后仍然重要的部分：清楚的边界、有效的信号、可重复的实验，以及出现问题时能够解释系统为何如此运行。
